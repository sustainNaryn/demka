# Умный полив для Нарына

Одностраничный дашборд на Next.js (App Router), Tailwind и Recharts. Прогноз на 7 дней берётся из [Open-Meteo](https://open-meteo.com/) для Нарына (широта 41.43, долгота 75.99) без API-ключа.

## Что на экране

- Выбор культуры и коэффициент Kc (`data/crops.ts`).
- Переключатель «Теплица»: осадки не учитываются, ET₀ умножается на коэффициент из `data/greenhouse.ts`.
- Карточка «Сегодня»: литры на 1 м² = max(0, ET₀ × Kc × множитель − осадки). Вердикт «Поливать» или «Не нужно».
- Предупреждение о заморозках, если минимум за 7 дней ≤ 0 °C.
- График: осадки столбцами, средняя температура и ET₀ линиями.
- Календарь полива с иконкой заморозка.
- Датчик почвы и заряд солнечной панели — подписаны как демо-данные.
- Счётчик сэкономленной воды против ежедневной нормы 6 л/м².

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Прогноз проксируется через `GET /api/weather`.
